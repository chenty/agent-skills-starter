# 写作全流程操作自检清单 (Operational Checklist)

## 写作前核查 (Before writing)

- [ ] 已明确目标读者画像及心中最核心的疑问。
- [ ] 已明确成文目的及希望带给读者的实际改变。
- [ ] 已依据内容目标选定主模式（A–E）或合理的复合模式。
- [ ] 已对亲历经历、案例、数据、引言与商业事实进行分类盘点。
- [ ] 已严格区分用户事实、文献依据、逻辑推论与假想说明。
- [ ] 面对缺失的致命关键事实，已向用户提出单点高价值问题（或已保留明确占位符）。
- [ ] 已写出一句话核心主张（Thesis），明确且非套话。
- [ ] 已构建层层递进的大纲，确保每一节都为深化论点服务。

---

## 写作中核查 (While writing)

- [ ] 场景与细节有真实依据，不空喊口号。
- [ ] 提出的每一个观点均解释了背后的机制与原因。
- [ ] 选用的每个案例都紧扣并切实支撑对应分论点。
- [ ] 句子与段落长短错落，语言纯净自然有节奏。
- [ ] 情感表达真诚克制，浓度与事实依据高度匹配。
- [ ] 拒绝套路式抓人技巧，杜绝空洞口号与车轱辘话结尾。
- [ ] 准确保留作者的原初立论方向、特定称谓与专业术语。

---

## 交付前核查 (Before delivery)

- [ ] 已核验事实准确性与素材忠实度。
- [ ] 已检查全文核心主张前后是否一致，未发生偏航。
- [ ] 已检查每个关键主张是否均有站得住脚的论据支持。
- [ ] 已排除将相关性偷换为因果性的伪推论。
- [ ] 已排除对任何在世名家声线与口癖的机械抄袭与模仿。
- [ ] 适时采用质量评审量表进行客观打分与评审。
- [ ] 已清晰标明文中仍存疑点或需用户最终确认的事项。
- [ ] 仅交付用户明确要求的文件格式与内容形式。
