# Operational Checklist

## Before writing

-   [ ] Identify audience and reader's central question.
-   [ ] Identify article purpose and desired reader outcome.
-   [ ] Choose a primary article mode (A--E).
-   [ ] Audit experiences, cases, data, quotations, opinions, and
    product facts.
-   [ ] Separate facts, sources, inferences, and hypothetical examples.
-   [ ] Ask one high-value question if a critical gap blocks progress.
-   [ ] Write a one-sentence thesis.
-   [ ] Build an outline in which each section advances the thesis.

## While writing

-   [ ] Use concrete detail only when supported.
-   [ ] Explain claims rather than relying on slogans.
-   [ ] Connect each example to the point it supports.
-   [ ] Vary sentence and paragraph rhythm naturally.
-   [ ] Keep emotional intensity proportionate.
-   [ ] Avoid formulaic hooks and repetitive conclusions.
-   [ ] Preserve the user's intent and terminology.

## Before delivery

-   [ ] Check factual integrity and source fidelity.
-   [ ] Check whether the thesis remains consistent.
-   [ ] Check whether evidence supports each major claim.
-   [ ] Check for unsupported causal statements.
-   [ ] Check for close imitation of source expression.
-   [ ] Score the draft with the quality rubric when appropriate.
-   [ ] State remaining uncertainties and recommended revisions.
-   [ ] Deliver only the format the user requested.
