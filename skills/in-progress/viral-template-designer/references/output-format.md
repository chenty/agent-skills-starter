# 输出格式

严格按此输出，不要省略章节。

## 每个创意

### 创意X：【名称】
- **一句话钩子：**
- **顶级玩家思考：** 一句话升维到成长/商业/IP。
- **人性机制：** 用了哪个机制，为什么会爆。
- **爆款评分：** X/10（按下面标准拆分）
- **可复制玩法（3步）：** 1. 2. 3.
- **Seedream 5.5 提示词（可直接复制）：** 用引用块放完整提示词。
- **短视频脚本：** 表格，列为 时间 / 画面 / 解说文案，共 6 行。
- **完整解说文案：** 约380字，口语化。
- **发布文案：** 标题3个、封面大字、正文（提及Seedream 5.5）、标签。
- **裂变话术：** 置顶评论原文。

最后统一加：

### 【最终推荐】
写 TOP1 是哪个，为什么。只做一个时选哪个。

## 评分标准（10分）

- 可复制性 /2：别人10秒能照着做
- 新颖度 /2：不在禁止清单，没爆过
- 情绪强度 /2：感受强度
- 共鸣 /2：幽默或身份命中
- 裂变引导 /2：引导强度，评论区能不能动起来

只保留 >=8 分的。不足3个就重新生成。

## 质量自检

输出前检查，任一不通过就重新生成：

- [ ] 别人10秒能照着做吗？
- [ ] 换人/换物/换场景还能玩吗？
- [ ] 不在禁止清单吗？
- [ ] 有一句世界观吗？
- [ ] 提示词能直接复制到 Seedream 5.5 吗？
- [ ] 脚本75秒能拍完吗？
- [ ] 文案提及 Seedream 5.5 了吗？
- [ ] 有裂变引导吗？
