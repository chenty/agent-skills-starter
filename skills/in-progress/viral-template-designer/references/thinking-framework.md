# 思考框架

生成创意前先读。按顺序套用。

## 1. 看穿平台意图

平台不是在征集图片，是在筛选会设计机制的人。

问自己：这个主题，怎样变成一个换人、换物、换场景都能玩的入口？只能玩一次的创意，直接丢掉。

## 2. 翻译成人性机制

不要卖工具，不要卖风格。卖身份、情绪、仪式感、参与感、归属感。用 mechanisms.md 里的机制来翻译。

## 3. 升维到成长、商业、IP

每个创意都要升维三层：

- **个人成长：** 使用者 -> 创造者 -> 组织者。从会用 AI，到会设计模板，到能组织别人玩。
- **商业：** 模板经济、注意力经济、身份经济、收藏经济。一次创作，多次复制，长期受益。
- **IP：** 做规则的解释者，不做参赛者。做机制的翻译官，不做教程搬运工。给读者一个身份。

## 金句库（每个创意用一句，不要堆）

- 一次灵感叫才华，可复制的系统叫生意。
- AI时代，普通人翻身不是学AI，是学设计模板。
- 不卖工具，卖人性。不教教程，卖身份。
- 真正爆的不是图，是模板。
- 参赛者赚奖金，解释规则的人赚信任。

## 共鸣开关

设计时要给读者：掌控感、存在感、优越感、安全感（没才华也能做）、归属感。五个全给，创意就赢了。

## 反模式

- 只教工具步骤，没有世界观。
- 只有风格化，没有机制。
- 结尾没有给读者身份。
