# 视频脚本和文案

## 75秒脚本结构

| 时间 | 目的 | 内容 |
|---|---|---|
| 0-3秒 | 钩子 | 立靶子：别再...了 / 你以为...错了 |
| 3-12秒 | 痛点 | 旧玩法已爆过，再做一张美图没人记得 |
| 12-25秒 | 升维 | 用 thinking-framework.md 里的金句 |
| 25-55秒 | 演示 | 录屏：上传 -> 粘贴提示词 -> 生成 |
| 55-65秒 | 证明 | 成品对比原图，展示可复制性 |
| 65-75秒 | 引导 | 给身份+行动：评论区留图，我帮你做同款 |

## 解说文案规则

- 75秒约 380 字中文。
- 短句，每句 <=15 字，口语化，不要书面语。
- 12-25秒放一句金句。
- 演示部分只讲 3 步。
- 结尾用裂变引导，不要只说点赞关注。

## 发布文案

- **标题（3个）：** 带挑战+好奇。句式：别再用Seedream 5.5只生成美图了 / 我用一张自拍做了一个能让1000人做同款的模板
- **封面大字：** <=6 字，带反差或身份。例：别做图，做模板
- **正文：** 必须提及 Seedream 5.5。写清模板、3步、裂变邀请。
- **标签：** 带 #Seedream5.5 + 主题标签。
- **置顶评论：** 评论区留下你的照片/场景/道具，我用Seedream 5.5帮你做同款

## 首帧

第一帧放成品模板，不要放工具界面。工具界面只出现在演示段。
