# 机制库

每个创意选 1-2 个机制，可以组合。

| 机制 | 商业翻译 | 适合 |
|---|---|---|
| 身份投射 | 人设经济，给用户一个想成为的身份 | 猎奇、全人群 |
| 年代/时间线 | 情绪经济，怀旧+集体记忆 | 走心、治愈 |
| 物化包装 | 仪式感+收藏经济，虚拟变实物 | 高级感 |
| 反差换头 | 幽默传播学，反差越大越好转 | 搞笑 |
| 过程反转 | 反完美主义，真实感=信任感 | 解压、扎心 |
| 系列收集 | 收集癖+成瘾机制，集齐一套 | 参与 |
| 二选一/站队 | 参与感，让人选边站 | 互动、讨论 |
| 假界面/假文本 | 梗文化+社交货币 | 搞笑、脑洞 |
| 创意分镜 | 叙事能力，日常变大片 | 高级感 |
| 场景融合 | 代入感+游戏化，你是主角 | 本地、游戏感 |
| 视角反转 | 脑洞经济，从物品/他人视角看你 | 新奇、低门槛 |
| 情绪具象化 | 把抽象情绪变成怪物/天气/报告 | 内耗、治愈 |
| 假文件/假证件 | 官方感+身份感 | 打工人、搞笑 |
| 属性面板/RPG卡 | 人设自嘲+标签经济，将现实身份与状态量化 | 游戏感、社交截图、共鸣 |
| 视觉谜题/猜梗 | 好奇心+互动飞轮，首图留白在评论区揭秘破圈 | 抽象梗、搞笑、打爆评论区 |
| 互动模拟/决策树 | 掌控感+沉浸停留，轻游戏化的分支剧情选择 | 强参与、微短剧感、长停留 |
| 复古手账/杂志撕页 | 去AI感手作美学+知识库，极致信息密度与质感 | 收藏比拉满、高级感、干货 |
| 情绪微缩/瓶中世界 | 空间具象化+精神庇护所，将内耗或瞬间封入景观 | 极致治愈、艺术感、情绪抚慰 |
| 反向劝退/听劝改造 | 反营销套路+养成系信任，以真实缺陷换取长期黏性 | 真实感、测评避坑、养成互动 |

## 禁止清单（不要复刻）

- 吉卜力 / 日式水彩风格
- AI手办盒 / 盲盒 / 3D公仔
- 宠物风格九宫格
- 人物九宫格证件照 / 工牌

角色档案卡、人生说明书、脑内小剧场、情绪天气预报、假头条、假Offer、物品视角、日常纪录片、房间游戏地图、给未来自己的信、AI分身替你上班、未来博物馆展签、人生二选一、假直播间PK、城市NPC、假账单/外卖单、专属表情包、人生进度条/读档、末日生存手册、成年生存考试卷、RPG人物属性面板、装备掉落清单、看图猜成语/谐音梗图、工位摸鱼模拟器、离职决策树、情绪微缩景观球、复古手账贴纸卡、杂志撕页笔记、深夜安全屋模型、听劝改造日记、防劝退避坑指南。
