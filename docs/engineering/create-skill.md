## What it does

`create-skill` 帮助用户把一项可复用的任务整理成符合本仓库规范的 agent 技能，也可依据观察到的问题改进已有技能。它从当前对话和现有文件提取需求，设计技能及调用边界，并同步元数据、文档和索引。

新生成的技能正文、文档页和元数据描述默认使用中文；只有用户明确要求其他语言或仓库另有规范时才切换。技能可按任务类型设计测试提示词，并在用户同意且运行环境支持时评估和迭代。

## When to reach for it

当你要从头创建一个可复用技能、把当前对话中的工作流整理成技能，或依据测试反馈改进已有技能时使用。若你只需要一条一次性提示词，直接写提示词即可；不必把它包装成技能。

## Where it fits

这是一个可由 agent 自动触发的工程类技能，负责技能的设计、仓库集成和迭代建议。它借鉴 Claude Skill Creator 的工作流程，但不会假装当前环境具备未安装的 Claude CLI、子代理或评估界面。结构检查通过也不代表技能已在真实任务中验证。

## Common questions

**需要先准备完整规格吗？**

不需要。它会先利用现有对话和仓库资料，只在缺失信息会改变技能目标、调用边界或安全行为时提出问题。

**新技能都会正式发布吗？**

不会。仍需验证的想法可以先放入 `in-progress/`；只有 `engineering/` 和 `productivity/` 分类的技能进入正式文档和插件清单。

**会自动运行评估吗？**

不会默认运行。它会先设计合适的测试；只有用户同意且环境具备可用的运行方式时才执行。否则会明确说明测试尚未运行。

## It's working if

- 新技能有清晰、独立的任务边界和调用策略。
- 指令告诉 agent 如何执行及检查结果，而不是只给泛泛建议。
- 文档、元数据、索引和生命周期分类彼此一致。
- `npm run check` 通过，且未把结构检查误称为实际效果验证。
