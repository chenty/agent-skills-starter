# 编写技能介绍页

介绍页帮助人决定何时使用技能；它不是 `SKILL.md` 的副本。

正式发布的 `engineering/` 与 `productivity/` 技能各有一个 `docs/<bucket>/<name>.md` 页面。实验、misc 和 deprecated 技能默认不创建新页面。正式技能被弃用时，可保留原页面并清晰标记状态与替代方案。

建议页面按以下顺序组织：

1. `## What it does`：一句话目标、核心行为约束。
2. `## When to reach for it`：触发场景及调用边界。
3. 可选的 prerequisites 或解释核心概念的段落。
4. `## Common questions`：真实的常见疑问。
5. `## It's working if`：用户可观察的成功信号。
6. `## Where it fits`：与其他技能、流程的关系。

保持页面简洁；每次改行为时核对介绍页、索引和插件清单。
