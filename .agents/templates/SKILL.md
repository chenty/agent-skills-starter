# Skill Name

## 目标

描述该技能要解决的具体问题，以及明确不负责什么。

## 适用场景

指出何时应使用此技能、何时不应使用。Model-invoked 技能的 description 应包含有用的触发语义。

## 流程

1. 明确需要的上下文和输入。
2. 执行最小、可验证的步骤。
3. 对重要分支给出选择标准。
4. 检查结果，并在失败或信息不足时说明下一步。

## 输出与完成条件

说明交付物、验证方式和停止条件。

## 边界与安全

说明不可假设的事实、需要用户确认的高影响操作，以及不得执行的行为。
